# Cerco de Jericó

Apresentação responsiva com dez slides, narração sincronizada e animações por letra.

Abra `index.html` no navegador. Áudio, logos e fontes estão incorporados; não há instalação ou build. Toque no botão de play central para iniciar os slides com áudio. Após iniciar, a apresentação repete em loop.

## Publicação no GitHub Pages

Em Settings → Pages, selecione **Deploy from a branch**, branch **main** e pasta **/ (root)**.

## Conteúdo

- `index.html`: apresentação completa, inclusive para uso offline.
- `narracao.mp3`: cópia da narração editada.

Narração extraída do vídeo https://www.youtube.com/shorts/ydTGzYsB9HY, do canal Ir Kelly Patricia OFICIAL / Instituto Hesed. Logos reconstruídos a partir das referências fornecidas. Fontes Noto Serif Display.
